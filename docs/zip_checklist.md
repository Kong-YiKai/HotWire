# Zip Checklist

Package the repository after you have generated a sample run and verified the README.

Exclude these items from the submission zip:

- `.venv/`
- `__pycache__/`
- `.pytest_cache/`
- `node_modules/` if one is ever created
- local `.env`
- build artifacts under `dist/`, `build/`, and `*.egg-info/`

Include these items in the submission zip:

- `README.md`
- `pyproject.toml`
- `src/`
- `scripts/`
- `tests/`
- `docs/demo_run_example.txt`
- `docs/zip_checklist.md`
