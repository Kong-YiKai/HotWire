# 项目中文说明

## 1. 项目简介

本项目是一个基于 Python 和 LangGraph 的多智能体协作系统。用户输入一个主题后，系统会通过三个不同角色的 Agent 协作，自动生成一篇高质量的博客文章或播客讲稿，并输出一份可用于展示协作过程的 Demo Log。

项目目标示例：

- 输入“最新的 AI 新闻”，输出一篇结构完整的博客文章
- 输入“2026 年新加坡旅游指南”，输出一篇适合播客的讲稿

## 2. 系统角色分工

项目中有三个核心 Agent：

### Researcher

- 负责联网搜索资料
- 只能调用 `web_search`
- 将原始研究内容和来源链接写入共享状态

### Analyst

- 不允许调用任何工具
- 只根据共享状态中的研究内容进行整理和分析
- 输出结构化要点和风险提示

### ChiefEditor

- 不允许联网搜索
- 只能调用内部工具 `word_count`
- 根据 Analyst 的结果生成最终 Markdown 文稿

## 3. 工作流程

系统采用串行工作流：

`Researcher -> Analyst -> ChiefEditor`

整体流程如下：

1. 用户输入主题和语气风格
2. Researcher 搜索资料并整理研究笔记
3. Analyst 将研究内容转成结构化要点
4. ChiefEditor 输出最终博客文章或播客讲稿
5. 系统保存最终 Markdown 文件和 Demo Log

## 4. 项目目录说明

建议组员重点关注以下目录和文件：

- `src/podcast_team/`：核心源代码
- `src/podcast_team/agents/`：三个 Agent 的实现
- `src/podcast_team/graph.py`：LangGraph 流程编排
- `src/podcast_team/state.py`：共享状态定义
- `src/podcast_team/tools.py`：工具定义，例如搜索和字数统计
- `src/podcast_team/cli.py`：命令行入口，支持终端问答式交互
- `tests/`：测试代码
- `docs/demo_run_example.txt`：示例 Demo Log
- `README.md`：英文版项目说明

## 5. 组员如何运行项目

### 第一步：进入项目目录

```powershell
cd d:\Workplaces\project\workshop
```

### 第二步：创建并激活虚拟环境

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 第三步：安装依赖

```powershell
pip install -e .
```

### 第四步：配置环境变量

先复制模板文件：

```powershell
Copy-Item .env.example .env
```

然后编辑 `.env`，填写自己的 OpenAI Key：

```env
OPENAI_API_KEY=你的真实OpenAIKey
```

注意：

- 不要把真实密钥写进 `.env.example`
- 不要把 `.env` 上传到 GitHub

## 6. 如何使用项目

### 方式一：终端问答式交互

直接运行：

```powershell
python -m podcast_team
```

终端会依次询问：

- 主题
- 输出风格
- 输出文件路径
- 是否启用 mock 模式

示例输入：

- Topic: `最新的AI新闻`
- Tone: `专业、清晰、适合博客文章`
- Mock: `n`

### 方式二：命令行直接传参数

```powershell
python -m podcast_team --topic "2026年新加坡旅游指南" --tone "轻松、生动、适合播客讲稿"
```

### 方式三：离线演示模式

如果没有 API Key 或只想演示流程，可以使用 mock：

```powershell
python -m podcast_team --mock
```

或者使用交互模式，最后一步选择 `y`。

## 7. 运行结果在哪里

程序运行后会输出两类结果：

### 最终文章

- 默认保存在 `output/final_markdown.md`

### Demo Log

- 自动生成在 `demo_runs/`
- 文件名格式为 `run_时间戳.txt`

Demo Log 中包含：

- 每个 Agent 的开始和结束
- 工具调用记录
- 输出摘要
- 权限边界说明

## 8. 测试方法

组员在提交代码前，建议至少跑一次测试：

```powershell
python -m unittest discover -s tests -p "test_*.py"
```

测试覆盖内容包括：

- 终端交互逻辑
- mock 模式端到端运行
- 日志生成
